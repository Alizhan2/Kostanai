# Работа двух участников

## Уже готово

Интерактивный прототип, симуляция трёх сценариев, расчёт показателей, прогноз буфера, журнал, импорт и отчёты. Созданы шесть макетов в Figma. Версия 0.4 содержит обученный лес деревьев для оценки исчерпания буфера; обучение и метрики доступны в `ml/`. Подготовлены сценарий защиты и черновик презентации. Обновлённый код пока локальный; публикация и авторы для сдачи не заполнены.

В версии 0.5 подготовлены импорт CSV истории, обучение с разделением смен по времени, шаблон полей команды, черновик письма и ответы жюри. Комплект собирается через `npm run release`. Реальная история не получена; новый маршрут CSV ещё не запускался.

## Участник 1 — интерфейс и демонстрация

- Прочитать README и пройти сценарий `docs/demo-script.md` на ноутбуке для защиты.
- Пройти обновлённый интерфейс 0.4 на ноутбуке и телефоне; предыдущий отчёт проверки относится к прежнему интерфейсу.
- Уточнить фактическую схему участков у организатора и заменить условную карту при наличии материалов.
- Подготовить доступную жюри ссылку на приложение или локальную копию для демонстрации.
- Записать резервное видео до 3 минут по сценарию.
- Проверить инструкции запуска после публикации репозитория.

## Участник 2 — данные и защита

- Уточнить у организатора наличие данных: мощности линий, выпуск, простои, дефекты, буферы и подача деталей.
- Подготовить снимок по схеме `docs/architecture.md`; явно отмечать синтетические данные.
- Проверить применимость формул и пороги риска с представителем предприятия.
- Изучить `ml/README.md`: модель обучена на синтетических сменах. Для следующего обучения собрать историю буфера, подачи, расхода, остановок и вмешательств; подготовить оценку по времени.
- Передать предприятию формат `ml/telemetry-format.md` и получить историю в CSV; хранить её в `ml/local/`.
- Добавить ФИО, учебное заведение и город; уточнить презентацию и расчёт эффекта.
- Собрать письмо со ссылками и проверить доступ без входа в аккаунт.
- Заполнить `docs/submission/team.json`, перенести авторов в презентацию и пересобрать комплект. Перед защитой пройти ответы из `docs/submission/jury-questions.md`.

Не отправлять черновик презентации как окончательный без данных об авторах и проверки ссылок. Дедлайн по объявлению — 8 октября 2026, 23:59; Demo Day в кейсе — 16 октября 2026. Часовой пояс дедлайна в сообщении не уточнён; следует ориентироваться на подтверждение организатора.
