# Отдельный файл проверки

`test-project.py` проверяет проект локально и сохраняет отчёт. Он ничего не публикует, не отправляет заявку, не обучает модели и не устанавливает зависимости автоматически.

Из каталога проекта:

```sh
npm ci
python3 test-project.py
```

То же через npm: `npm run test:project`.

Обычная проверка запускает существующие тесты расчётов, CSV и экономики, проверку синтаксиса, сверку моделей с сохранёнными Python-предсказаниями, ссылки и файлы готовой сборки, автора и скриншоты в презентации, содержимое PowerPoint. Для извлечения текста PDF используется `pypdf`; если он не установлен, именно эта проверка отмечается `SKIPPED`, а заголовок PDF проверяется независимо. Это не проверка внешней доступности Canva или регистрации команды.

Для проверки интерфейса с автоматическим локальным сервером:

```sh
python3 test-project.py --browser
```

Нужны Python Playwright и Chromium по пути `/usr/bin/chromium`, как в существующем браузерном сценарии. Здесь проверяются остановка/восстановление, импорт JSON/CSV, отчёты, денежный расчёт, диагностика Scania, таймер и все семь разделов на ширинах 390/768/1440 px. Сервер запускается на свободном порту localhost и закрывается после проверки. Внешний интернет для приложения не нужен.

Если исходники приложения изменились, пересоберите их в той же команде:

```sh
python3 test-project.py --build --browser
# либо
npm run test:project -- --build --browser
```

`--build` обновляет каталог `site/`. Остальные результаты пишутся в `.test-results/`, который исключён из Git: `latest.json`, логи, модельный отчёт, браузерные снимки и скачанные тестовые файлы. Проверка без `--browser` явно отмечает интерфейс как `SKIPPED`; наличие файлов сборки не означает проверку её работы в браузере.

Итог `PASSED` означает успешность выполненных проверок. Код завершения — `0` при успехе, `1` при сбое; пропуски перечисляются отдельно. При сбое подробности находятся в соответствующем логе. Регистрация, отправка заявки, промышленная применимость и настоящая экономия Allur этим файлом не подтверждаются.
