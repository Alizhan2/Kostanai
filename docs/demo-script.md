# Сценарий защиты — 3 минуты

Перед показом: открыть `index.html` или локальную ссылку, нажать «Сбросить». Масштаб браузера 100%; выбрать обзор завода. Все данные синтетические.

**0:00–0:25 — проблема.** «Мы собрали цифровой двойник производственной цепочки: руководитель видит состояние участков, выпуск и отклонения. На демо — условная схема четырёх участков, а не реальная телеметрия Allur».

**0:25–0:50 — обзор.** Показать карту, выбрать сборочную линию, открыть карточку. Объяснить: выпуск завода считается по финальной сборке, а загрузка — относительно мощности.

**0:50–1:35 — прогноз и остановка.** «В буфере 12 комплектов. Расход 20 в час, подача — 4. При сохранении потока запас закончится через 45 минут». Показать причины и дополнительный прогноз тренда. Нажать «+5 минут» девять раз; появляется остановка, карта меняет статус. Ещё один шаг увеличивает простой.

Рядом показать блок «Обученная модель · демо»: «Лес из 64 деревьев оценивает исчерпание запаса на 60 минут при меняющейся подаче. Он обучен на синтетических сменах. Эта оценка и индекс риска по правилам имеют разный смысл». На отложенных сменах полнота 90,2%, точность предупреждений 72,6%; на заводской истории оценки пока нет.

**1:35–2:05 — действие.** «Оператор пополняет буфер и восстанавливает подачу». Нажать «Пополнить буфер». Показать низкий риск и возобновление выпуска после двух шагов. Открыть инциденты: причина устранена; затем отчёты: действие записано.

После пополнения ML-оценка временно недоступна, пока не накопятся три новые точки минимум за 10 минут. Это ожидаемое поведение: старая история падения буфера не используется для нового прогноза.

**2:05–2:30 — данные и отчёт.** Показать импорт JSON и экспорт CSV; при нехватке времени показать кнопки без выполнения. «Модель принимает проверенный снимок. Следующий этап — адаптер данных предприятия».

**2:30–3:00 — эффект и границы.** «В нашем двухчасовом сценарии пополнение через 30 минут устраняет 75 минут моделируемого простоя и даёт примерно 25 дополнительных автомобилей. Это результат симуляции, не измерение на заводе. Для внедрения нужно проверить прогнозы на реальных потоках и истории остановок».

Если браузер сохранил старый снимок, кнопка «Сбросить» восстанавливает начальные данные. Если нет интернета, приложение продолжает работать: внешние ресурсы не нужны.

Полнота 97,1%, точность предупреждений 41,7%; низкий порог выбран из-за высокой стоимости пропуска. Модель классифицирует APS и другие неисправности. Заводской буфер и время будущей поломки в этом наборе не представлены».
