# Проверка версии 0.7.0

Проверено 2 октября 2026: Node.js 24, Chromium, локальный HTTP-сервер. Сценарий проверки: выбор времени пополнения в отчётах → независимая симуляция → график и таблица → скачанный JSON. Сравнение полностью локальное.

## Расчёты

`npm test`: **15/15 пройдено** — 12 регрессионных тестов производственного движка и 3 теста нового сравнения. `npm run check`: синтаксис девяти JavaScript-файлов корректен.

Проверена известная граница исчерпания запаса через 45 минут:

| Пополнение через | Простой без действий | Простой с пополнением | Предотвращённый простой |
|---:|---:|---:|---:|
| 0 минут | 75 | 0 | 75 |
| 30 минут | 75 | 0 | 75 |
| 45 минут | 75 | 0 | 75 |
| 60 минут | 75 | 15 | 60 |
| 120 минут | 75 | 75 | 0 |

Позднее действие уменьшает дополнительный выпуск. Действие в конце горизонта не меняет двухчасовой результат. Неверные значения времени отклоняются. Повторный расчёт воспроизводит результат; начальные накопленные выпуск и простой исключены.

`npm run compare` использует общий модуль с интерфейсом. Для 30 минут: выпуск без действий 14,8, с действием 40 эквивалентных авто; дополнительный выпуск 25,3 и предотвращённый простой 75 минут. Показатели округлены независимо.

## Браузер

- Главная страница и отчёты загружаются с данными и элементами управления.
- Начальное значение ползунка 30 минут отображает ожидаемые результаты, две кривые, время действия и таблицу.
- Клавиши Home, End и ArrowRight выбирают начало, конец и следующий шаг 5 минут. В конце горизонта дополнительный выпуск и предотвращённый простой равны нулю.
- Текстовое значение и `aria-valuetext` ползунка обновляются. Фокус сохраняется при изменении значения. Выбор сохраняется после перехода между обзором и отчётами через мобильное меню.
- После изменения параметра сохранённое производственное состояние в localStorage совпадает с исходным.
- Скачанный JSON для 30 минут полностью совпадает с результатом общего расчётного модуля, содержит исходные допущения и 25 точек графика.
- На ширине 390 px документ остаётся шириной 390 px; карточка — 358 px. Мобильные подписи графика увеличены; точные значения доступны в таблице.
- Ошибок JavaScript, неудачных загрузок обязательных ресурсов и внешних запросов не обнаружено.

## Сохранённые проверки и ограничения

Артефакты моделей, признаки и вычислители прогноза не менялись. Их хеши совпадают с проверенными в 0.6.1. Сохранён результат сравнения JavaScript и Python на 20 443 записях, допуск 10⁻¹⁰; повторное обучение и повторная проверка переноса в 0.7 не выполнялись. Предыдущие браузерные проверки Scania, остановки и восстановления описаны в [отчёте 0.6.1](verification-0.6.1.md).

Заводская история Allur отсутствует; маршрут подготовки и обучения на внешнем CSV ещё не выполнялся. Новый эксперимент использует начальный синтетический сценарий задержки деталей и сохраняет текущую смену. Его результат не подтверждает эффект на предприятии или качество ML-прогноза.

Запуск проверен через HTTP; `file://` и публичное размещение не проверены в этой версии. Авторы, данные команды и публикация кода остаются незавершёнными. Машиночитаемый результат с хешами — [latest.json](verification/latest.json).
