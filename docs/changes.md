# Изменения проекта

## 0.5.0 — 2 октября 2026

- Добавлена подготовка внешней истории сборки из CSV с проверкой времени, чисел и причин остановок.
- Признаки вычисляются общим модулем с браузером; после вмешательств и разрывов история начинается заново.
- Смены разделяются по времени. Смены, пересекающие границы, неполные горизонты, окна с вмешательствами и другими причинами остановки исключаются.
- Обучение и графики поддерживают отдельные папки результатов для внешней истории. Текущая демо-модель остаётся артефактом обучения версии 0.4.
- Добавлены шаблон CSV, описание формата, поля команды, черновик письма и ответы жюри.
- Добавлена сборка ZIP, копии PDF и перечня файлов с SHA-256 через `npm run release`. Внешние данные в `ml/local/` в комплект не включаются.

Новый маршрут подготовки и обучения ещё не выполнялся: заводская история не предоставлена. Программные тесты и браузерные сценарии в этом обновлении не запускались.

## 0.4.0 — 2 октября 2026

Обучен лес из 64 деревьев на синтетических сменах, добавлены калибровка, общий вычислитель признаков, браузерный прогноз, отчёт и графики. На 119 отложенных сменах precision 72,6%, recall 90,2%; F1 баланса потоков выше. Обновлена PDF-презентация.

## 0.3.0 — 2 октября 2026

Интерфейс перенесён на стили макетов Figma, добавлены локальные шрифты и SVG-иконки, история буфера, расширенная таблица линий и адаптивная сетка.
