# Комплект для сдачи

Кейс №2: «Цифровой двойник автомобильного завода», Allur. Команда состоит из двух участников. Дедлайн из объявления: 8 октября 2026, 23:59; часовой пояс требуется уточнить у организатора.

## Файлы

- `../presentation.pdf` — восемь слайдов, пока черновик с незаполненными авторами.
- `team.json` — поля для названия команды, учебного заведения, города и двух участников.
- `submission-email.md` — подготовленное письмо; оно не отправлялось.
- `jury-questions.md` — ответы для защиты.
- `../../dist/Allur-Plant-Twin.zip` — архив после запуска сборки.
- `../../dist/submission-status.json` — состав архива, контрольные суммы и недостающие поля.

## Завершение

1. Заполнить `team.json`: ФИО капитана и второго участника, учебное заведение, город, название команды и адрес получателя.
2. Перенести авторов на первый слайд исходника `../presentation.html` и сохранить обновлённый PDF.
3. Опубликовать код в указанном репозитории и поставить `repositoryPublished: true` после публикации. Поле фиксирует заявление команды; сборка не проверяет доступность GitHub.
4. При наличии заполнить `presentationUrl` и `demoUrl`. PDF можно приложить к письму.
5. Пересобрать комплект командой `npm run release` и сверить список недостающих полей.

Сборка работает на стандартном Python, создаёт письмо и ZIP, исключает `ml/local/`, виртуальное окружение и каталог результатов сборки. Код в GitHub, сайт и письмо она не публикует. Для ответа жюри на вопрос о данных используйте формулировку «синтетическая демонстрация, качество на предприятии ещё не оценено».
