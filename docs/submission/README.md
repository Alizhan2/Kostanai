# Комплект для сдачи

Кейс №2: «Цифровой двойник автомобильного завода», Allur. Команда состоит из двух участников. Дедлайн из объявления: 8 октября 2026, 23:59; часовой пояс требуется уточнить у организатора.

Подробная проверка кейса, положения и комплектности — [отчёт соответствия](../compliance-review.md). Его список включает регистрацию, раскрытие AI-инструментов и канал подачи; сборка ZIP эти условия не проверяет.

Код опубликован в [репозитории](https://github.com/Alizhan2/Kostanai), ветка `main`. Проверены публичные чтения без авторизации: README, приложение, package.json, PDF и техническое описание. Доказательства — [publication.json](publication.json). PDF остаётся черновиком без авторов; публикация кода не означает подачу заявки.

## Файлы

- `../presentation.pdf` — девять слайдов, пока черновик с незаполненными авторами.
- `team.json` — поля для названия команды, учебного заведения, города и двух участников.
- `submission-email.md` — подготовленное письмо; оно не отправлялось.
- `jury-questions.md` — ответы для защиты.
- `../technical-description.md` — архитектура, источники, внешние компоненты и использованные AI-инструменты.
- `../../dist/Allur-Plant-Twin.zip` — архив после запуска сборки.
- `../../dist/submission-status.json` — состав архива, контрольные суммы и недостающие поля.

## Завершение

1. Заполнить `team.json`: ФИО капитана и второго участника, учебное заведение, город, название команды и адрес получателя.
2. Перенести авторов на первый слайд исходника `../presentation.html` и сохранить обновлённый PDF.
3. Проверить актуальность опубликованного кода и доступность ссылки перед сдачей. `repositoryPublished: true` установлен после публикации и чтения файлов без авторизации. Сборка сама не проверяет GitHub; опубликованный снимок зафиксирован в `publication.json`.
4. При наличии заполнить `presentationUrl` и `demoUrl`. PDF можно приложить к письму.
5. Пересобрать комплект командой `npm run release` и сверить список недостающих полей.

Сборка работает на стандартном Python, создаёт письмо и ZIP, исключает `ml/local/`, виртуальное окружение и каталог результатов сборки. Код в GitHub, сайт и письмо она не публикует.
