## Перед отправкой

1. Подтвердить регистрацию; получатель уже внесён в `team.json`: `smart_center@ksu.edu.kz`.
2. Приложить PDF и указать код репозитория в том же письме. PPTX и Canva остаются рабочими форматами и не заменяют PDF.
3. Выполнить `npm run release`: `dist/submission.eml` содержит готовый черновик с PDF, `dist/submission-body.txt` — текст для копирования. Сверить `dist/submission-status.json`.
4. Проверить черновик в своей почте, выбрать аккаунт отправителя и отправить одно письмо. Сохранить подтверждение приёма. Провести репетицию на три минуты.

Сборка не отправляет письмо и не проверяет регистрацию. Скриншоты отражают русский интерфейс работающего прототипа; слайдовый текст на казахском. Зауыт симуляциясы синтетикалық; Scania диагностикасы — отдельный модуль на открытых данных. Эффект на Allur ещё не измерен.

## Условия видео

Новое сообщение организатора требует ссылку на видео только при таком условии выбранного кейса. В №2 запрошены интерактивный прототип/MVP и демонстрация сценариев; отдельная обязательная ссылка на видео не указана. §6.2 положения допускает работающий прототип, демоверсию либо видеодемонстрацию. Проект и инструкция запуска доступны в репозитории. [Зафиксированные требования](delivery-requirements.json).

`readyToSubmit` в JSON означает заполненность полей и наличие PDF, а не отправку, подтверждение регистрации или приём оргкомитетом. EML — локальный черновик без аккаунта отправителя; на сервере он ничего не отправляет.
