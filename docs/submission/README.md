## Перед отправкой

1. Подтвердить регистрацию и адрес получателя; вписать `recipientEmail` в `team.json`.
2. Проверить ссылки на код и PDF; при необходимости приложить PDF непосредственно.
3. Выполнить `npm run release`, сверить `dist/submission-status.json`. Архив и копии PDF/PowerPoint появятся в `dist/`.
4. Провести репетицию на три минуты, проверить запуск на ноутбуке и отправить материалы через канал организатора.

Сборка не отправляет письмо и не проверяет регистрацию. Скриншоты отражают русский интерфейс работающего прототипа; слайдовый текст на казахском. Зауыт симуляциясы синтетикалық; Scania диагностикасы — отдельный модуль на открытых данных. Эффект на Allur ещё не измерен.
