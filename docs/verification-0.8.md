# Проверка версии 0.8.0

Проверено 2 октября 2026 UTC / 3 октября Asia/Oral. Node.js 24, Vite 8.3.2, React 19.3.0 и Chromium. Проверка выполнялась на готовой сборке `site/`, а не только в режиме разработки.

## Результаты

- `npm test`: 19/19 — 16 производственных проверок и 3 сравнения сценариев.
- `npm run check`: девять JavaScript-файлов прошли проверку синтаксиса; JSX проверен сборкой Vite.
- `npm run build`: готовая статическая React-сборка без предупреждений; отдельные части приложения, React и модели.
- `npm run verify:models`: 4 443 синтетические записи буфера и 16 000 Scania APS. Решения JavaScript совпадают с Python, максимальная разница вероятностей <10⁻¹⁰. Повторное обучение не требовалось: изменились интеграция модулей и интерфейс, а не деревья моделей.
- Браузер: остановка сборки через 45 минут, накопление простоя, пополнение, карточка оборудования и Escape, автоматический таймер с паузой в карточке/настройках, отклонение окраски и исправление.
- Импорт: ошибочный JSON сохраняет прежнюю смену; импортированные остановки оборудования остаются остановками после шага и пополнения. Синтетический ML на импортированных данных отключён. Перезагрузка сохраняет происхождение снимка и ставит симуляцию на паузу.
- Отчёты: ползунок меняет независимый сценарий, сохраняет значение при навигации и не меняет текущую смену. Скачаны и проверены CSV, TXT, снимок JSON и сравнение JSON.
- Все семь страниц помещаются на ширинах 390, 768 и 1440 px; прокрутка таблицы остаётся внутри контейнера. Браузерных ошибок не обнаружено. На отдельной странице Scania проверены вычисления для исходных записей обоих классов.
- Раздел источников показывает факты задания и неизвестные корпоративные показатели отдельно; экспорт каталога сохраняет неизвестную мощность как `null`.

В готовой сборке обнаружены и исправлены две ошибки интеграции: отсутствие браузерного API при обработке общих модулей Vite и отсутствующий базовый стиль отдельной диагностики Scania. Проверка после исправлений прошла.

## Воспроизведение

```sh
npm ci
npm test
npm run check
npm run verify:models
npm run build
npm run preview
```

В другом терминале, если установлены Python Playwright и Chromium (`/usr/bin/chromium`):

```sh
python3 scripts/verify-react.py --url http://localhost:4173
```

Проверка браузера создаёт локальные снимки и скачивает отчёты во временные файлы. Машиночитаемые результаты — [react-browser.json](verification/react-browser.json), [latest.json](verification/latest.json). Скриншоты — [ПК](react-desktop.png), [телефон](react-mobile.png).

## Ограничения

Официальные сайты Allur ограничены сетевой политикой среды; корпоративная статистика, логотип и палитра не подтверждены. Каталог содержит контекст официального кейса, а не производственную телеметрию. Заводская модель и её обучающие данные синтетические; Scania APS — отдельная диагностика грузовиков.

Не проверены реальные интеграции, промышленная применимость, регистрация команды и фактическая подача материалов. Авторы и реквизиты команды не заполнены. Публичное размещение приложения как сайта не выполнено; готовая локальная сборка включена в репозиторий и архив. Запуск через `file://` не поддерживается.
