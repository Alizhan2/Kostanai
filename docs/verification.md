# Проверка версии 0.9.0

4 октября 2026, Asia/Oral. Проверены расчёты, готовая React/Vite-сборка и работа в Chromium через локальный HTTP.

## Результаты

- `npm test`: **26/26** — 16 проверок производственного движка, 3 сравнения сценариев, 3 денежных расчёта и 4 CSV.
- `npm run check`: 11 JavaScript-модулей; JSX дополнительно проверен успешной сборкой `npm run build`.
- Браузер: **17 групп сценариев**, включая остановку, восстановление, качество, импорт, отчёты, сравнение, таймер и ширины 390/768/1440 px. Ошибок console/runtime нет.
- Денежный расчёт: пустые начальные поля; при ставках 100 000 ₸/ч и 20 000 ₸ ранний баланс 105 000 ₸, поздний 80 000 ₸. В конце горизонта нет действия и списания платы. Отрицательная ставка отклоняется; значения сохраняются при навигации. Допущения и результат включены в скачанный JSON. Значения являются условиями проверки, а не ценами Allur.
- CSV: ошибочная схема и файл больше 1 МБ сохраняют смену; экспортированный снимок загружается обратно с сохранением остановок и происхождением imported. Скачанный шаблон успешно импортируется.
- Парсер проверен на BOM, кавычках, запятых, точках с запятой, табуляции, десятичной запятой. Пустые числа, формулы, повторённые заголовки, неверные метаданные и обход ограничений движка отвергаются.
- Все семь страниц помещаются в проверенные ширины; максимальные допустимые денежные значения также проверены на телефоне.

Деревья, признаки, вычислители ML и обучающие наборы не менялись. Сохранённая сверка JavaScript и Python на 20 443 записях относится к этим же артефактам; повторное обучение в 0.9 не выполнялось. Браузерная диагностика Scania проверена заново для записей двух классов.

## Воспроизведение

```sh
npm ci
npm test
npm run check
npm run build
npm start
```

При установленном Python Playwright и Chromium `/usr/bin/chromium`, в другом терминале:

```sh
python3 scripts/verify-react.py --url http://localhost:8000
```

Машиночитаемые результаты: [react-browser.json](verification/react-browser.json) и [latest.json](verification/latest.json). Экономика: [ПК](economics-desktop.png), [телефон](economics-mobile.png). Предыдущая проверка: [0.8](verification-0.8.md).

## Практические ограничения

Заводская модель синтетическая; CSV-снимок не подтверждает происхождение данных. Цены и эффективность Allur не установлены. Денежный расчёт не включает налоги, неопределённость и все затраты внедрения. Подключение к MES, большие IoT-платформы и обучение на заводской истории не выполнялись.

Анализ рынка ограничен документированными возможностями четырёх соседних решений и выбранного CSV-компонента; размера рынка, цен и спроса нет. Презентация обновлена на казахский язык: 10 слайдов, пять скриншотов, авторы Zhubanov team. Данные команды предоставлены пользователем; регистрация и отправка заявки не подтверждены.
