# Проверка версии 0.6.1

Проверено 2 октября 2026. Среда: Node.js 24, Chromium, локальный HTTP-сервер. Проверка охватывает производственную симуляцию и отдельную диагностику Scania APS. Все перечисленные ниже проверки выполнены после исправлений.

## Производственный движок

`npm test`: **12/12 пройдено**. Проверены баланс потоков, момент остановки внутри шага, простой, восстановление, очистка тренда, регрессия, качество, принятие инцидента, импорт и завершение смены.

Новая регрессионная проверка сравнивает 45 минут одним шагом, тремя шагами по 15 и девятью по 5. Во всех случаях буфер равен нулю, линия остановлена, выпуск равен нулю, простой составляет 2 минуты. Через следующие 5 минут простой равен 7; инцидент остановки остаётся один.

Исправлена причина расхождения: остаток порядка 10⁻¹⁵ комплекта после вычитания чисел с плавающей точкой удерживал статус «Внимание». При расходовании буфера остаток менее 10⁻⁹ комплекта теперь приводится к нулю.

`npm run check`: синтаксис восьми JavaScript-файлов корректен. Повторная генерация синтетической выборки после исправления не изменила её SHA-256: `1f3dd44feaa9c477425484b4cf5ae01cfd3fbcc2e65f8d82f1a8201901def7e2`. Артефакт обученной модели остаётся совместимым.

## Перенос моделей из Python в браузер

`npm run verify:models` сравнивает JavaScript-вычисления с сохранёнными предсказаниями scikit-learn на исходных отложенных записях, включая заполнение пропусков и калибровку.

Допуск — 10⁻¹⁰. Это проверка переноса модели, а не дополнительная оценка её применимости. Полный результат — [model-export.json](verification/model-export.json).

## Браузерные сценарии

- Из отчётов приложения открывается диагностика Scania; реальные примеры содержат 170 признаков. Результат и исходный класс показаны отдельно.
- Некорректный JSON отклоняется с сообщением на русском. Предыдущие данные, вероятность, исходный класс и скачиваемая запись сохраняются. Раньше ошибка заменяла панель результата; это исправлено.
- Выгрузка наблюдения и повторная загрузка сохраняют вероятность 20,3%. После загрузки без эталонной метки исходный класс обозначается как неизвестный. Успешная загрузка скрывает прежнюю ошибку.
- Переключение на пример другого компонента даёт 0% и статус ниже порога. Диагностика не меняет сохранённое состояние производственных линий.
- Девять шагов по 5 минут останавливают сборку при нулевом буфере. Следующий шаг увеличивает простой. Пополнение восстанавливает линию и очищает историю ML; прогноз появляется снова после двух следующих наблюдений.
- Все шесть разделов приложения и диагностика Scania проверены при ширине 390 px. Ширина документа не превышает ширину экрана; содержимое доступно.
- Ошибок JavaScript нет. Обязательные ресурсы загружены; внешних запросов при работе интерфейса нет.

## Ограничения и сдача

Проверка выполнена через локальный HTTP-сервер. Запуск через `file://` не подтверждён: политика Chromium в этой среде блокирует такой доступ. Публичное размещение приложения не проверялось.

Заводская история Allur не предоставлена. Подготовка и обучение на внешнем CSV ещё не выполнялись. Симуляция и прогноз буфера используют синтетические данные; Scania APS решает другую задачу диагностики компонента грузовика. Проверка интерфейса не подтверждает качество прогноза на заводе.

Данные команды и авторов презентации не заполнены, код ещё не опубликован в репозитории. Комплект остаётся черновиком для сдачи. Машиночитаемая запись проверки с хешами исходников — [latest.json](verification/v0.6.1.json).
